        使用说明与几个约定

        一杯 = 一个固定杯型。中杯和大杯是两条独立的饮品，各自带 ml、咖啡因、热量。记录时不用再填毫升。
        咖啡因怎么算？「上限 − 今天每一杯」。默认 400mg，每记一杯扣掉这杯的咖啡因，扣到 0 为止。记录面板里会直接告诉你「喝完这杯，今天还剩多少」。
        便利店买的那种（比如瓶装乌龙茶）冰度和糖度改不了，所以不出现这两个选项。
        热量是哪来的？瑞幸丝绒拿铁是 352kcal（大杯／少冰／全糖，从瑞幸 App 查的）；Manner 咸芝士拿铁 355ml 是 240kcal；霸王茶姬白雾红尘大杯 296kcal。查不到官方的按同类估算，可以在饮品库里直接改。
        糖度会影响热量吗？不会。热量按这杯的固定值记，半糖／无糖只当备注。
        价格每次都不一样？保存前把「实付价格」改成这次真正付的钱（用了券就填券后价），统计都按实付算。
        想记一个库里没有的？「记一杯」里点「＋ 新饮品」，填名字、杯型 ml、咖啡因、热量就行。
        怎么备份？点「导出备份」会下载一个 JSON 文件，换设备时用「导入备份」还原。
